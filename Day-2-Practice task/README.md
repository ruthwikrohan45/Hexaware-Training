# Day 2 – Java Practice Tasks

This folder contains the three Day 2 practice programs.

## 1. HashMapExample.java
Demonstrates HashMap using mobile phone names and prices:
- `put()` adds entries.
- `get()` retrieves a value.
- `entrySet()` iterates through key-value pairs.
- `put()` updates an existing value.
- `remove()` deletes an entry.

## 2. LinkedListDemo.java
A manually implemented singly linked list:
- Insert at beginning, end, and a given position.
- Delete from beginning, end, and a given position.
- Display all nodes.
- Search for a value.

## 3. TreeTraversal.java
A Binary Search Tree:
- Insert a node.
- Inorder traversal.
- Preorder traversal.
- Postorder traversal.

## How to run
Open the Day-2 folder in IntelliJ IDEA and run each Java file separately.
